Kelas Setara is a modern Learning Management System (LMS) focused on hands-on programming learning experiences. Built as a Single Page Application (SPA) using Vue 3, Tailwind CSS, and Supabase, the platform integrates Monaco Editor and Pyodide to allow students to write and execute code (such as Python) directly in the browser without requiring third-party infrastructure setup. It is designed with an open-source vision for easy adaptation by various educational institutions.
